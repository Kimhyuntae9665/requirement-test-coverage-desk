# Diagram and media provenance

Architecture SVG glyphs are original geometric drawings created for this repository; they are not vendor trademarks. Each card is square, its glyph remains proportional, and every label names an actual implementation role. Qwen is optional: its proposals pass through the same source rules and human review as the explicit-link baseline. No embedding or vector database is used for twelve test definitions.

Style reference: a user-approved synthetic layout/compatibility image was materialized and visually inspected. Reference pixels and private Library identifiers are not included in current public files. It is not a claimed architecture. The approved dark dotted background, white rounded cards, curved arrows and glyph labels were matched.

All screenshots and the demonstration video are captured from this implementation with Playwright. Fixture measurements displayed in the UI are fictional; browser interaction recordings do not measure the mock service acknowledgement SLO. CPU test results are actual execution of this repository's engine and HTTP tests. Model trace files record actual bounded local Qwen evaluation attempts; they never imply semantic coverage acceptance or certified performance.

Current UI evidence is in `artifacts/ui-refit/`; prior `artifacts/media/` is historical. The current README images and video show actual CPU-only Chrome interaction with this UI. Exact byte counts and SHA256 hashes, unchanged frozen-file hashes, baseline commit and video duration/dimensions are in [provenance](../artifacts/ui-refit/provenance.json). No model calls or real service-performance measurements were made during the UI refit. No Library upload was performed: the known media transfer path remains blocked; public repository media is the available deliverable.
